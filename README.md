# UDNAseq Reproducibility

## Overview
This project analyzes uracil enrichment in *Plasmodium falciparum* DNA through DNA-seq
experiments.

## Purpose
Investigate uracil incorporation patterns in the malaria parasite genome using reproducible computational workflows.

## Contents
- Analysis scripts
- Data processing pipelines
- Results and figures

## Getting Started
1. Clone the repository
2. Install dependencies
3. Run analysis scripts in the `scripts/` directory

## Requirements
- Python 3.x
- Required packages listed in `requirements.txt`
